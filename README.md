## What is this?

Wix powers 200M+ websites. For years, none of them could be converted into a PWA.

This app changes that.

**Convert to App (PWA)** lets any Wix site owner turn their website, online store, or web app into a cross-platform installable app — without writing a single line of code and without building a separate native app.

---

## Features

- **Works instantly** — iOS, Android, and Desktop
- **Cross-platform** — Chrome, Edge, Brave, Samsung Internet, Firefox (Android), Safari (iOS 16.4+)
- **Installable** — users can add the site to their home screen like a native app
- **Analytics** — track app installs and opens
- **Push Notifications** — available on Premium plan (re-building becauseof Wix platform changes)
- **Offline Support** — coming soon
- **5-minute setup** — no technical knowledge required

---

## Why I built this

I'd been building on Wix for 5 years when I hit this wall.

PWA support existed on WordPress, Shopify, and almost every other major platform. Wix had nothing. The community had been asking for it for years. Nothing happened.

So I spent 1–2 years figuring out how to make it work on Wix's architecture — while simultaneously prepping for JEE. Shipped it in September 2024. It's been growing since.
